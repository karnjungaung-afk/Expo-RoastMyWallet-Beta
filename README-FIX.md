# RoastMyWallet — SDK 57 fix bundle

These files are replacements for the current `RoastMyWallet/` app root on `main`.

## What changed

- Synced app dependencies to Expo SDK 57 / React 19.2.3 / React Native 0.86.3.
- Added `react-native-worklets` required by Reanimated 4.x.
- Added `react-native-web` and `react-dom` for the web target; the repo's previous dev log showed `react-native-web` resolution failure.
- Removed the obsolete manual Reanimated Babel plugin; Expo's Babel preset configures it automatically.
- Added TypeScript path aliases matching the `@/` and `@app/` imports.
- Added the missing `src/services/supabase.ts` client.
- Updated notification foreground behavior to the SDK 57 `shouldShowBanner` / `shouldShowList` fields.
- Fixed `ColorValue` typings in both tab layouts.
- Added normal Expo / Node / env ignores.

## Replace

Copy the contents of this bundle into your existing `RoastMyWallet/` folder, overwriting the matching files.

## Reinstall cleanly

From inside `RoastMyWallet/`:

```bash
rm -rf node_modules package-lock.json
npm install
npx expo install --fix
npm run typecheck
npx expo-doctor
npx expo start --clear
```

Do not copy the old `package-lock.json` back. It is still locked to the older dependency tree and should be regenerated by npm after the new `package.json` is in place.

## Environment

Keep your Supabase values in `.env` / `.env.local` and do not commit secret files.

Required variables used by the current config are:

```text
EXPO_PUBLIC_SUPABASE_URL=
EXPO_PUBLIC_SUPABASE_ANON_KEY=
EXPO_PUBLIC_API_BASE_URL=
APP_ENV=development
AI_ENABLED=true
EAS_PROJECT_ID=
```
